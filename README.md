
# AI Placement Preparation Assistant

## Project Description

AI Placement Preparation Assistant is an AI-powered
application that helps students prepare for technical
placement interviews.

It generates personalized interview questions based
on the candidate's job role, experience, domain,
difficulty level and number of questions.

## Technologies Used

- Python
- LangChain
- OpenRouter API
- Streamlit
- Pydantic
- LangSmith

## Features

1. Select job role.
2. Select experience level.
3. Enter technical domain.
4. Choose question difficulty.
5. Select number of questions.
6. Generate interview questions using AI.

## Installation

Install the dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app.py

## Testing

python test.py
